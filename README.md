# Download Manager

A free Windows desktop download manager by **Aashir Sheraz**, built with Electron, React and TypeScript.

[Visit the website](https://simplyaashir.github.io/download-manager/) · [Download Windows setup](https://github.com/simplyAashir/download-manager/releases/download/v1.0.3/DownloadManager-Setup-1.0.3-x64.exe)

## What we built

- Download queue, progress tracking and history, with parallel connections for compatible servers.
- Chrome and Edge companion extension for sending links to the app.
- Light, Dark, Blue and Green themes, plus a system theme option.
- Windows 10/11 x64 installer with bundled runtime and media tools, tray operation and startup controls.
- Public website with app previews, installation instructions and direct installer downloads.

This repository hosts the website and public releases. Application source and internal development files remain private.

The installer is unsigned. Browser extension setup requires one-time approval; instructions are on the website.
